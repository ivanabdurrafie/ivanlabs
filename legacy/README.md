# Modern Minimalistic Developer Portfolio

A clean, professional portfolio website for backend developers with frontend design capability, featuring:

## Features

- **Modern Minimalistic Design**: Clean aesthetic with content-based spacing (no viewport gaps)
- **Professional Engineering Tone**: Backend-focused positioning with frontend capability
- **Responsive Layout**: Mobile-first design with 3 breakpoints (480px, 768px, 1024px)
- **Dark Mode Support**: Automatic detection with manual toggle
- **Performance Optimized**: Fast loading with minimal dependencies
- **Accessibility Focused**: WCAG touch targets (44x44px minimum), semantic HTML, proper contrast ratios
- **CV-Aligned Content**: Accurate representation of skills and experience
- **Enhanced Navigation**: Compact sidebar with key-links-only on small screens (About, Systems, Connect)
- **Advanced Animations**: Optimized GSAP animations with adjusted thresholds for shorter sections
- **Visual Feedback**: Enhanced hover effects and interactive elements
- **Scroll Progress Indicator**: Visual progress tracking during navigation
- **Brutalist Aesthetic**: Sharp corners, high contrast borders, monochrome palette

## Design Goals

- Clean minimalistic 2026 developer portfolio style
- Professional engineering tone with strong typography hierarchy
- Content-based spacing system (eliminates scroll fatigue from viewport heights)
- Responsive mobile-first layout with dark mode support
- Brutalist Swiss design with sharp 2px borders and pure #000000/#FFFFFF palette

## Responsive Breakpoints

- **Desktop (1024px+)**: Vertical sidebar navigation (80px width)
- **Tablet (768px-1024px)**: Compact vertical sidebar (60px width), adjusted grids
- **Mobile (480px-768px)**: Horizontal top navbar (60-70px height), full link set
- **Very Small (<480px)**: Horizontal compact navbar (50px height), key links only (About, Systems, Connect)

## Structure

- **Hero Section**: With name, title, and call-to-action buttons
- **About Section**: Concise summary of backend architecture experience
- **Skills Section**: Organized in categories (Backend, Architecture, Database, Tools)
- **Projects Section**: Engineering achievements with problem/solution/impact format
- **Case Study Section**: Detailed engineering improvement example
- **Experience Timeline**: Measurable achievements instead of responsibilities
- **Education Section**: Academic background and qualifications
- **Download CV Section**: Direct download of full resume
- **Contact Section**: Essential contact information

## Technology Stack

- HTML5, CSS3, JavaScript (ES6+)
- Modern CSS features (variables, grid, flexbox)
- Intersection Observer API for animations
- Semantic HTML for accessibility

## Customization

To customize this portfolio for your own use:

1. Update the content in `index.html` with your own information
2. Modify the CSS variables in `style.css` for your preferred color scheme
3. Adjust the font choices in both HTML and CSS files if desired
